How to get a Serper API key
  1. Sign up free at serper.dev (new accounts get free credits).
  2. Open Dashboard → API Key and copy the key.
  3. Paste it above and press Save key. It is checked with Serper and kept only for your account; only its last 4 characters are ever shown.
  4. Running low? Paste a new key here any time — it replaces the old one at once, even in the middle of a search. No need to log in again.
